# 📚 Adopting and maintaining the template

**English** | [Italiano](../README.md)

The template extracts reusable choices from Chiara Corrado's website and uses
neutral example content. These guides explain the decisions to maintain or
adapt as you add content and features.

| Guide | When to use it |
| --- | --- |
| [Architecture and JavaScript](ARCHITECTURE.md) | Before adding an interaction or dependency |
| [Accessibility](ACCESSIBILITY.md) | For every new page or state |
| [Images](IMAGES.md) | When adding photographs, illustrations or diagrams |
| [Quality and release](RELEASE.md) | Before publishing and on the final domain |
| [Sustainability and WSG](SUSTAINABILITY.md) | To document decisions, evidence and maintenance |

The companion [Web Weight Toolkit](https://github.com/kiaruzza/web-weight-toolkit)
contains the full tools handbook: WSG, EcoIndex, Ecograder, Network, Lighthouse,
PageSpeed Insights, WebPageTest, axe, WAVE, Orca, Squoosh, Green Web Check,
carbon.txt, CO2.js, Firefox Profiler and Impact Framework.
The complete handbook is available in the toolkit repository.

## Languages and navigation

Every guide and Markdown template links to its equivalent Italian edition.
The repository's main README is English; `README.it.md` is Italian.
`translations.json` records document pairs. When changing a procedure, update
both languages together. CSV template translations are listed in the handbook.
Index icons accompany text labels rather than replacing them. Scripts and
report keys use English in both editions.
