# 📚 Adottare e mantenere il template

[English](en/README.md) | **Italiano**

Il template è un'estrazione del sito di Chiara Corrado, con contenuti neutrali.
Queste guide spiegano le decisioni che vanno mantenute o adattate quando si
aggiungono contenuti e funzioni.

| Guida | Quando usarla |
| --- | --- |
| [Architettura e JavaScript](ARCHITETTURA.md) | Prima di aggiungere un'interazione o una dipendenza |
| [Accessibilità](ACCESSIBILITA.md) | Per ogni pagina o stato nuovo |
| [Immagini](IMMAGINI.md) | Quando si aggiungono fotografie, illustrazioni o diagrammi |
| [Qualità e rilascio](RILASCIO.md) | Prima della pubblicazione e sul dominio definitivo |
| [Sostenibilità e WSG](SOSTENIBILITA.md) | Per documentare scelte, evidenze e manutenzione |

Il progetto complementare [Web Weight Toolkit](https://github.com/kiaruzza/web-weight-toolkit)
contiene il manuale completo degli strumenti, con WSG, EcoIndex, Ecograder,
Network, Lighthouse, PageSpeed Insights, WebPageTest, axe, WAVE, Orca, Squoosh,
Green Web Check, carbon.txt, CO2.js, Firefox Profiler e Impact Framework.
Il manuale completo è disponibile nel repository del toolkit.

## Lingue e navigazione

Ogni guida e modello ha un collegamento alla versione inglese equivalente.
Il README principale del repository è in inglese, `README.it.md` in italiano.
La corrispondenza dei documenti è registrata in `translations.json`: quando
cambi una procedura, aggiorna entrambe le lingue nello stesso intervento.
Le icone degli indici affiancano etichette testuali, senza sostituirle.
Gli script e le chiavi dei report usano l'inglese in entrambe le edizioni.
